### 👨‍💻 Sobre mí

Desarrollador **Full Stack** enfocado en la construcción de aplicaciones web escalables, arquitecturas limpias y sistemas empresariales. Apasionado por el rendimiento, la robustez del código y la automatización de pruebas end-to-end.
